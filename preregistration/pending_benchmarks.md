# Pending benchmark values

This register lists every value in the Stage 1 protocol that a benchmark run before submission will settle. The protocol states each registered rule in full, but some of the figures beside those rules are provisional. They come from public gold and public stories, and a few are expected values that no run has produced yet. None was computed on a story text, and none will be, before in-principle acceptance.

Each provisional value carries a comment with its identifier, `<!-- PENDING: Pnn -->` in the Markdown and Quarto files, so that a search for `PENDING` finds every one. An identifier can mark more than one place when the same figure appears in several. The pre-submission benchmarks in the feature plan's schedule (version 3, revised 22 October 2026) settle them. Weeks 1 and 2 run from 26 October to 8 November 2026, weeks 3 and 4 from 9 to 22 November, and weeks 5 and 6 from 23 November to 6 December. When a benchmark has run, its final value replaces the provisional text, the comment is deleted and the row below is removed. A value that the benchmark changes is carried into every place that quotes it, and `tools/check_citations.py` and `preregistration/check_reported_numbers.R` are re-run.

Locations name the file, the section and the opening words of the paragraph or table cell, because line numbers drift.
